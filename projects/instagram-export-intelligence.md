# 📊 Instagram Export Intelligence

> Local-first analytics for the data people are allowed to download, but rarely able to understand.

Instagram Export Intelligence turns official Instagram/Meta **Download your information** archives into structured, inspectable data.

## The idea

Exported archives are fragmented: JSON files, multipart follower lists, activity records, connection data, and metadata spread across folders. This project makes that information usable without asking for an Instagram password, scraping the platform, or uploading the archive anywhere.

`raw export → validation → normalized models → local DuckDB → metrics → dashboard / reports`

## What it enables

- 🔎 Snapshot comparisons instead of one-off, static exports.
- 🤝 Clear follower/following relationship metrics.
- 📈 Local reports and dashboard views for activity and content metadata.
- 🔐 Privacy-aware analysis: no login, browser automation, unofficial API, or cloud upload required.
